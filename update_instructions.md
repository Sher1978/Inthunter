## 🚀 3. Пошаговая инструкция по деплою и настройке сервера

### Шаг 3.1. Размещение Nginx конфигурации
Скопируйте настройки из файла `server_optimization.conf` на ваш продуктовый сервер (например, в `/etc/nginx/sites-available/leadradar.conf`).

Основные элементы конфигурации:
```nginx
# 301-редирект с HTTP на HTTPS и с www на канонический домен https://leadradar.win
server {
    listen 80;
    server_name leadradar.win www.leadradar.win;
    return 301 https://leadradar.win$request_uri;
}

# Включение Gzip-сжатия кода (сокращение объема до ~75%)
gzip on;
gzip_types text/plain text/css application/json application/javascript text/xml image/svg+xml;

# Кэширование статических файлов (30 дней)
location ~* \.(jpg|jpeg|png|gif|ico|css|js|svg|woff2)$ {
    expires 30d;
    add_header Cache-Control "public, no-transform";
}
```

Выполните перезапуск Nginx:
```bash
sudo nginx -t
sudo systemctl reload nginx
```

### Шаг 3.2. Регистрация в Google Search Console и Яндекс.Вебмастере
1. Зайдите в [Google Search Console](https://search.google.com/search-console).
   - Добавьте свойство `https://leadradar.win/`.
   - Перейдите в раздел **Файлы Sitemap** и отправьте URL: `https://leadradar.win/sitemap.xml`.
   - В разделе **Проверка URL** запросите индексацию главной страницы `https://leadradar.win/`.
2. Зайдите в [Яндекс.Вебмастер](https://webmaster.yandex.ru/).
   - Добавьте сайт `https://leadradar.win/`.
   - В меню **Индексирование -> Файлы sitemap** добавьте `https://leadradar.win/sitemap.xml`.
   - В разделе **Инструменты -> Проверка микроразметки** вставьте код страницы и убедитесь, что валидатор видит граф `Organization`, `Service`, `FAQPage`.

### Шаг 3.3. Проверка ИИ-индексации (Generative Engine Optimization)
1. Проверьте доступность файла `https://leadradar.win/llms.txt` в браузере или через `curl`:
   ```bash
   curl -I https://leadradar.win/llms.txt
   ```
2. Отправьте запрос в Perplexity.ai или ChatGPT:
   *«Что такое LeadRaDaR и как он находит покупателей недвижимости в Дубае и Вьетнаме?»*
   Нейросеть сможет мгновенно извлечь точные факты из вашего `/llms.txt` и графа `FAQPage`.
