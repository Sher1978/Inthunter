# Воронки Пользователей и Telegram-Бот

Бот (`src/bot`) написан на Aiogram 3 и служит основным интерфейсом для онбординга, оплаты и получения лидов конечными клиентами (B2C/B2B партнерами).

## Роли Пользователей (Партнеров)

Определены в модели `Partner` (`src/db/models.py`).
1.  **DEMO:** Выдается при первой регистрации (`/start`). Пользователь получает $10 тестового баланса. Может смотреть список лидов, но видит только обрывки контактов.
2.  **REGULAR:** Получает после первого пополнения баланса (реальными деньгами). Может покупать лидов, но видит их с задержкой (например, через 10 минут после VIP).
3.  **VIP:** Платная подписка. Лиды доставляются мгновенно (Push-уведомления).
4.  **ADMIN / SUPERADMIN:** Полный доступ к TMA-дашборду управления каналами, логам ИИ и статистике.

## Ключевые Воронки (Funnels)

### Воронка Покупателя (B2C / B2B)
1.  Пользователь переходит в бота (обычно по реферальной ссылке).
2.  Нажимает `/start` -> Срабатывает `start_handler` (`handlers.py`).
3.  Бот создает профиль в БД, выдает DEMO баланс.
4.  Пользователь открывает TMA (Mini App) по кнопке "Открыть Радар".
5.  Внутри TMA выбирает лида и нажимает "Купить".
6.  Деньги списываются с внутреннего баланса, лид переходит в статус `SOLD` (если эксклюзив) или привязывается через `LeadPurchase`. Бот присылает прямую ссылку на клиента.

### Воронка B2B-Подрядчика (Outreach)
Это автоматизированная воронка внутри сканера (Функция Splitter).
1.  Юзербот читает чат и находит пост "Ремонтирую кондиционеры, звоните!".
2.  VQS оценивает его в 70+ баллов -> Это `VENDOR_OFFER`.
3.  Запись падает в таблицу `OutreachLead`.
4.  **Менеджер (или ИИ-Агент "Екатерина"):** Подхватывает контакт из базы и пишет ему в личку: *"Привет! Вижу, вы занимаетесь ремонтом. У нас есть готовые клиенты на эту услугу, дать пару контактов?"* (Sales Hook).
5.  Подрядчик переходит в нашего бота -> Становится Покупателем (Funnel 1).

## Уведомления и Алерты (`alert_bot.py`)
Специальный модуль для Push-уведомлений и оперативных отчетов:
*   `broadcast_lead_alert`: Рассылает VIP-пользователям уведомление о новом лиде в их нише.
*   `run_hourly_superadmin_digest_loop`: Формирует часовой дайджест прослушки и квалифицированных лидов.
*   `run_dead_channel_watchdog_loop`: Ежедневный вочдог неактивных каналов (7+ дней без сообщений). Собирает все неактивные каналы в единую **сводную карточку (Grouped Digest Card)** вместо одиночного спама сообщениями.
*   `broadcast_debug_scan`: Рассылает суперадминам системные логи в режиме реального времени (для отладки).

### 🌙 Ночной Режим Тишины (Quiet Hours: 00:00 – 06:00 UTC+7)
1. **Приостановка отправки:** В период **с 00:00 до 06:00 утра (UTC+7)** абсолютно все автоматические Push-уведомления, дайджесты, лид-алерты и отчёты о неактивных каналах **блокируются на отправку**, гарантируя тишину ночью.
2. **Группировка и возобновление:** По завершении ночного режима тишины (в 06:00 UTC+7) возобновляется отправка сообщений. Накопленные статусы (например, сводки мертвых каналов) приходят **единой групповой карточкой-отчетом**, не заспамляя ленту пользователя.
