# Веб-Интерфейс (TMA) и API

Веб-приложение (Telegram Mini App) реализовано как Single Page Application на связке **HTML + Vanilla JS + Tailwind CSS**. Серверная часть работает на **FastAPI**.

## Структура TMA
Файлы расположены в папке `static/`:
*   `index.html`: Главная разметка, разделенная на "экраны" (Views), которые переключаются через JS.
*   `app.js`: Вся логика фронтенда (роутинг, API-запросы, рендеринг списков, модальные окна).
*   `style.css`: Кастомные стили (Tailwind импортируется через CDN).

### Основные разделы интерфейса (Views)
1.  **Маркетплейс (`#marketplace-view`):** Витрина лидов для клиентов. Поддерживает фильтрацию по нишам и локациям.
2.  **Мои Лиды (`#my-leads-view`):** Список уже купленных лидов (открытые контакты).
3.  **Дашборд Управления (`#admin-view`):** Доступен только SUPERADMIN. Позволяет добавлять каналы на прослушку.
4.  **ИИ Логи (`#ai-logs-view`):** Доступен только SUPERADMIN. Показывает в реальном времени поток сообщений, проходящих через ИИ-Анализатор и Gatekeeper.
5.  **Терминал / Все процессы (`#live-logs-container`):** Бегущая строка логов работы скраперов (от модуля `process_logger.py`).

## API Сервер (`src/api/routes.py`)

FastAPI предоставляет REST-эндпоинты под префиксом `/api/`.

### Ключевые маршруты:
*   `GET /api/leads`: Получить список лидов (учитывает купленные пользователем).
*   `POST /api/leads/{lead_id}/purchase`: Купить лида (списывает баланс).
*   `GET /api/collector/logs`: Получить статистику скрапера (для дашборда).
*   `GET /api/collector/ai-logs`: Получить Chain-of-Thought логи (`AIEvaluationLog`).
*   `GET /api/stream`: Server-Sent Events (SSE) эндпоинт для трансляции "бегущей строки" терминала в реальном времени на фронтенд.

## Авторизация (Telegram WebApp Data)
В TMA нет логинов и паролей.
Авторизация происходит через валидацию строки `window.Telegram.WebApp.initData`.
На сервере этот процесс реализован в `src/api/tma_auth.py`, который криптографически проверяет подпись с использованием токена бота. Это гарантирует, что запросы к API делает реальный пользователь Telegram.
