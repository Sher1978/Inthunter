# 🚀 Архитектура и Функционал Системы B2C-Лидгена и Утилизации Вакансий (HR-Radar)

Данный документ содержит полное техническое описание B2C-системы монетизации вакансий и лидогенерации работы **HR-Radar**, построенной на едином бэкенде и базе данных **LeadRadar**.

---

## 🏗️ 1. Общая Архитектура

Система использует концепцию **раздельного фронтенда на едином ядре**:

```
                                 [ Единый ИИ-Парсер (Бэкенд & DB) ]
                                                │
                   ┌────────────────────────────┴────────────────────────────┐
                   │ (Интент: Покупка / Заказ услуг)                         │ (Интент: Найм / Вакансия / HR)
                   ▼                                                         ▼
       [ B2B-Система LeadRadar ]                               [ B2C-Система HR-Radar ]
   (Твои бот-аккаунты & @LeadRadarBot)                                       │
                                                ┌────────────────────────────┴────────────────────────────┐
                                                ▼                                                         ▼
                                 [Канал-Витрина (Публичный)]                                   [VIP-Бот (Закрытый B2C)]
                                 ──> Задержка публикации: 30 мин                               ──> Мгновенный PUSH
                                 ──> Контакты полностью скрыты                                ──> Открытые контакты HR
                                 ──> Кнопка: "Узнать контакт"                                 ──> Тарифы: $7/нед, $19/мес, Stars
                                                │                                                         │
                                                └────────────────────────────┬────────────────────────────┘
                                                                             ▼
                                                                [Апсейл: AI Resume / Cover Letter]
```

### Ключевое правило архитектуры:
- **LeadRadar (`@LeadRadarBot`)** — B2B-продукт для предпринимателей и компаний, покупающих клиентов ($299/мес).
- **HR-Radar (`@HR_Radar_Bot` + Канал-Витрина)** — B2C-продукт для соискателей работы ($7–$19/мес).
- **Единый бэкенд и БД**: Парсер и ИИ-классификатор работают в один поток, но автоматически разводят B2B-лиды и B2C-вакансии по разным таблицам и телеграм-каналам.

## ⚡ 2. Логика и Поток Данных (Flow)

### Шаг 1: Сканирование и Сбор Постов
1. **Pyrogram MTProto Userbot** посекундно читает 200+ локальных Telegram-групп (Дубай, Нячанг, Бали, РФ).
2. Каждое новое сообщение отправляется в нейросетевой классификатор (`AIRotatorEngine`).

### Шаг 2: ИИ-Классификация (Intent Engine)
Нейросеть (SambaNova / Cerebras / Groq / Gemini) определяет категорию:
- Если интент `EMPLOYER_HIRING_VACANCY` (работодатель ищет сотрудника, вакансия):
  1. Создаётся запись `HRVacancy` в базе данных PostgreSQL.
  2. Запускаются два параллельных процесса доставки (см. Шаг 3).

### Шаг 3: Дифференцированная Доставка по Тарифам

#### A. Мгновенная доставка VIP-подписчикам (VIP PUSH)
- **Задержка:** `0 секунд` (Мгновенно).
- **Контакты:** **ОТКРЫТЫ** (`@username` HR или прямой юзернейм).
- **Кому отправляется:** Подписчикам `@HR_Radar_Bot`, имеющим активный `TRIAL` ($7) или `VIP` ($19) статус, если вакансия совпадает с их тегами ниш (`#Маркетинг`, `#Недвижимость`, `#Разработка` и т.д.).

#### B. Публичный Канал-Витрина (Traffic Magnet)
- **Задержка:** **30 минут** (`asyncio.sleep(1800)`).
- **Контакты:** **СКРЫТЫ / БЛЮР** (`🔒 Скрыты. Опубликовано с задержкой 30 мин`).
- **Интерактивная кнопка:** `[ 🔓 Узнать контакт и откликнуться первым ]` $\rightarrow$ веден на глубокую ссылку бота `t.me/HR_Radar_Bot?start=vac_{vacancy_id}`.

## 💾 3. Модели Базы Данных (`src/db/models.py`)

### 1. `HRVacancy` — Вакансии
- `id` (UUID): уникальный идентификатор вакансии.
- `title` (String): заголовок должности.
- `company_name` (String): название компании / работодателя.
- `location_code` (String): регион (`dubai`, `nhatrang`, `bali`, `russia`).
- `niche_code` (String): тег ниши (`#Маркетинг`, `#Недвижимость`, `#Разработка`, `#Логистика`).
- `salary_text` (String): вилка зарплаты (например, `$3,500 – $4,500`).
- `description` (Text): описание задач и условий.
- `hr_contact` (String): контактный телефон / юзернейм HR.
- `author_username` (String): прямая ссылка на Telegram работодателя.
- `status` (String): `PUBLISHED`, `ARCHIVED`.

### 2. `HRSubscriber` — База Соискателей
- `telegram_id` (BigInteger): ID соискателя в Telegram.
- `username` / `first_name`: личные данные.
- `subscription_status`: `FREE`, `TRIAL`, `VIP`.
- `subscription_expires_at`: дата и время окончания платного доступа.
- `subscribed_tags` (JSON): список выбранных тегов для PUSH.

### 3. `HRSubscriptionPayment` — Журнал Платёжных Транзакций
- `plan_code`: `TRIAL_7D` ($7), `VIP_30D` ($19), `STARS_TRIAL`.
- `amount_usd`: сумма в USD.
- `payment_provider`: `TELEGRAM_STARS`, `CRYPTO`, `STRIPE`, `DEMO_TEST`.

## 💰 4. Воронка Монетизации (Monetization Engine)

```
[Пользователь видит посты в Канале-Витрине (с задержкой 30 мин и без контактов)]
                                    │
                                    ▼
[Нажимает "🔓 Узнать контакт" и переходит в @HR_Radar_Bot]
                                    │
                                    ▼
       ┌────────────────────────────┴────────────────────────────┐
       │ Пользователь БЕЗ подписки                               │ Пользователь С ПОДПИСКОЙ
       ▼                                                         ▼
[Пейволл-экран в боте:                                    [Мгновенное открытие прямых
 • Trial Pass: $7 / неделя                                  контактов HR + кнопка
 • VIP Pass: $19 / месяц                                    "Написать HR"]
 • Telegram Stars: 350 Stars]
```

### Тарифная сетка:
1. **Trial Pass ($7 / 7 дней)** — пробный доступ для тех, кому нужно быстро найти работу в течение недели.
2. **VIP Pass ($19 / 30 дней)** — полный доступ со всеми тегами и мгновенными PUSH-уведомлениями.
3. **Telegram Stars (350 ⭐️)** — встроенная покупка внутри Telegram без ввода банковских карт.

## 🔌 5. Интеграция с ИИ-Маршрутизатором (`src/ai/scorer.py`)

При обработке сообщения нейросеть выставляет флаги. В функции `evaluate_user_timeline`:
1. Если определена вакансия `hr_hiring`:
   ```python
   from src.bot.hr_bot import route_new_vacancy

   new_vac = HRVacancy(
       title=scoring_result.sales_hook,
       description=scoring_result.intent_summary,
       author_username=author_uname,
       salary_text=ext_data.salary if ext_data else None,
       location_code=loc_code
   )
   session.add(new_vac)
   await session.commit()

   # Вызов маршрутизатора
   await route_new_vacancy(new_vac)
   ```

2. `route_new_vacancy`:
   - Мгновенно отправляет PUSH в VIP-бот.
   - Запускает `asyncio.create_task(schedule_showcase_delayed_posting(new_vac.id, delay_seconds=1800))` на 30 минут для канала-витрины.

## 📊 6. Управление и Мониторинг в Веб-Панели (LeadRadar Admin)

В `src/api/routes.py` добавлены REST API эндпоинты:
- `GET /api/hr/vacancies` — просмотр всех найденных вакансий, фильтрация по статусу и региону.
- `GET /api/hr/subscribers` — список соискателей и активных VIP-подписчиков.
- `GET /api/hr/stats` — аналитика: количество вакансий за 24 часа, количество подписчиков, выручка в USD/Stars.
