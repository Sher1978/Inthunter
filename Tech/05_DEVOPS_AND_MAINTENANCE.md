# DevOps, Деплой и Обслуживание

Проект спроектирован для работы в облачных PaaS-средах (например, Railway, Heroku) с минимальным вмешательством человека.

## Запуск проекта

Главная точка входа объединяет запуск FastAPI (uvicorn) и Aiogram (asyncio) в одном event-loop.
Команда запуска:
```bash
python -m src.api.app
```

## Переменные окружения (.env)
*   `BOT_TOKEN`: Токен Telegram бота (от BotFather).
*   `USERBOT_SESSION_STRING`: (Опционально) Сессия Pyrogram для чтения закрытых групп.
*   `GROQ_API_KEYS`, `GEMINI_API_KEY`: Ключи для LLM. Поддерживается перечисление через запятую для ротации.
*   `DATABASE_URL`: Строка подключения к БД (SQLite по умолчанию `sqlite+aiosqlite:///data/app.db`).
*   `MAX_DB_SIZE_MB`: Лимит размера базы (по умолчанию 400MB).

## Автономное обслуживание (Database Guard)

Поскольку проект собирает тысячи сырых сообщений (телеметрия) каждый день, бесплатные базы данных на Railway (обычно лимит 500MB) могут быстро переполниться.
Для этого создан демон `src/services/db_guard.py`.

### Что делает DB Guard:
1.  **Контроль размера:** Каждые N минут проверяет физический размер файла БД.
2.  **Удаление логов:** Удаляет старые записи `UserActivityLog` (сырые сообщения) и `CollectorLog` (статистика сканера), старше 1 часа / 3 часов.
3.  **Удаление спама:** Срок хранения мусорных логов (`AIEvaluationLog` с `is_lead=False`) строго ограничен 3 часами.
4.  **Безопасность Лидов:** Записи квалифицированных лидов (`Lead`) и пользователей (`Partner`) **никогда не удаляются** чистильщиком (у них бесконечный срок хранения).
5.  **Emergency Vacuum:** Если размер БД превышает 400MB, скрипт принудительно удаляет 50% старых логов и запускает команду `VACUUM` (для SQLite) для сжатия дискового пространства.

## Ограничения (Rate Limiting)
*   **Скрапер:** Не делает более 1 запроса в секунду к одному каналу.
*   **Юзербот:** Ждет 12-15 минут между вступлениями в новые группы (защита от FloodWait). Спит ночью (по локальному времени сервера).
*   **API:** LLM-ротатор переключает API-ключи, если получает код 429 от провайдера Groq/OpenAI.
