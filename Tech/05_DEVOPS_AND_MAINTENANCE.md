# DevOps, Деплой и Обслуживание

Проект спроектирован для автономной работы в облачных PaaS-средах (Railway, GitHub Actions) с минимальным вмешательством человека.

## Запуск проекта

Главная точка входа объединяет запуск FastAPI (uvicorn) и асинхронные фоновые сервисы в одном event-loop:
```bash
python -m src.api.app
```

При старте функция `init_db()` производит сидинг 3 активных юзерботов в таблицу `ScraperAccount`, предотвращая ошибки `406 AUTH_KEY_DUPLICATED`.

## Переменные окружения (.env)
*   `TELEGRAM_BOT_TOKEN`: Токен основного Telegram бота (от BotFather).
*   `TELEGRAM_API_ID`, `TELEGRAM_API_HASH`: Ключи доступа Telegram API.
*   `GEMINI_API_KEYS`, `GROQ_API_KEYS`, `OPENROUTER_API_KEY`: Ключи для LLM-ротатора.
*   `DATABASE_URL`: Подключение к базе данных PostgreSQL (Railway) или SQLite (`sqlite+aiosqlite:///intent_hunter.db`).

## Автономное обслуживание (Database Guard & Emergency Clean)

Бесплатные базы данных на Railway имеют лимит объема диска 500 МБ.
Для предотвращения сбоев дисковой квоты работает демон `src/services/db_guard.py`.

### Что делает DB Guard:
1.  **Проверка условий:** Раз в 15 минут проверяет размер базы данных и количество записей в `UserActivityLog`.
2.  **Порог экстренной очистки:** Если размер базы превышает **30 МБ** или число логов превышает **3000 строк**, демоном автоматически выполняется:
    *   `TRUNCATE TABLE user_activity_logs, ai_evaluation_logs, collector_logs;`
    *   `VACUUM FULL;` (для освобождения дискового пространства в PostgreSQL).
    *   `CHECKPOINT;` (для немедленного удаления старых WAL-файлов с диска).
3.  **Безопасность лидов:** Данные таблиц `Lead`, `Partner`, `HRVacancy`, `ScraperAccount` **никогда не затрагиваются** при очистке.

### 1-Клик Очистка из браузера:
Для принудительного освобождения диска в любой момент достаточно открыть URL:
👉 `https://www.leadradar.win/api/admin/emergency-clean`

### Очистка через Railway Web Console:
В веб-терминале Railway (вкладка Console) для вставки скопированных команд используется комбинация **`Ctrl + Shift + V`** или **Правая кнопка мыши -> Вставить**.

## Ограничения и Защита от Банов (Rate Limiting)
*   **Юзерботы**: 3 аккаунта в режиме `ACTIVE` с лимитом не более 20 подписок в день и джиттером 12-15 минут. 12 аккаунтов находятся в резерве (`DISABLED`).
*   **ИИ-Ротатор**: Автоматический переход между провайдерами при коде `429` с кулдауном 5 минут.
